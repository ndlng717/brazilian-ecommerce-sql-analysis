# Brazilian E-Commerce SQL Analysis

This project analyzes a Brazilian e-commerce dataset using SQL in PostgreSQL.  
The goal is to explore customer behavior, revenue drivers, and delivery performance.

---

## Dataset

The dataset contains information about:

- Customers
- Orders
- Order items
- Sellers
- Payments
- Reviews
- Product categories
- Geolocation

---

## Database Schema

The dataset was structured into multiple relational tables:

customers  
orders  
order_items  
payments  
reviews  
products  
sellers  
category_translation  
geolocation  

---

## SQL Skills Demonstrated

This project demonstrates several SQL techniques including:

- JOIN operations
- GROUP BY and HAVING
- Window functions
- CTEs (Common Table Expressions)
- CASE statements
- Date functions
- Ranking functions
- Percentile calculations

---

## Key Business Questions

The analysis answers several business questions:

1. Which seller states generate the most revenue?
2. Do higher shipping costs affect customer review scores?
3. Which months generate the highest revenue?
4. What is the lifetime value of customers?
5. Are repeat customers more satisfied?
